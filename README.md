В header прописаны имя, фамилия и подзаголовок страницы. 
В main расположены изображение с атрибутами src, alt, width, height, две секции с маркированным и нумерованным списками, а также форма обратной связи с полями text, email, textarea и кнопкой отправки. У всех полей заданы атрибуты name и placeholder. 
В aside вынесена краткая информация об области науки, любимых технологиях и контактном email. 
В footer указан копирайт с годом. 
Стилизация выполнена встроенным CSS в светло-голубой и темно-синей гамме.
